# Contributing

Pull requests are accepted only from forks.

1. Fork the repository.
2. Open the pull request from a branch on your fork into `main` here.
3. Keep the change focused. `npm test` and `npm run build:web` must pass.

A pull request whose head branch lives in this repository is rejected by CI. Push fixes to your fork. Maintainer commits on `main` are unaffected.

Report security issues as described in [SECURITY.md](SECURITY.md). Do not open a public issue for an unfixed vulnerability.
